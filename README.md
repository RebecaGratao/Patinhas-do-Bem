----------DESCRIÇÂO----------
O Patinhas do Bem é um sistema desenvolvido como parte das atividades do SENAI, 
voltado à adoção de animais, permitindo o cadastro e gerenciamento de usuários, perfis e animais disponíveis para adoção. 
A plataforma facilita a busca por animais e o acesso às suas informações, 
além de auxiliar no processo de adoção de forma organizada e prática.

----------FUNCIONALIDADES----------
*Cadastro e gerenciamento: usuários, perfis e animais disponíveis para adoção.
*Adoção: busca de animais, visualização de informações, favoritos e solicitações de adoção.
*Comunicação:** notificações e suporte para facilitar o contato entre adotantes e responsáveis pelos animais.

----------API'S UTILIZADAS----------
*ViaCEP: utilizada para consulta e preenchimento de endereços a partir do CEP.
*Google Maps: utilizada para localização e visualização de endereços no mapa.
*WhatsApp Cloud API: utilizada para facilitar a comunicação entre adotantes e responsáveis pelos animais.
*Resend: utilizada para envio de e-mails, como confirmações e notificações do sistema.
*Mercado Pago: utilizada para processar pagamentos e doações, permitindo opções como Pix e cartão.
